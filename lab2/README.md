## Выполнение индивидуального задани (Вариантт 3):
## Задание:
### Построить график этой функции и касательную к ней. 
### Добавить на график заголовок, подписи осей, легенду, сетку, а также аннотацию к точке касания.
![img_35.png](img/img_35.png)
## Решение:
### Касательная к графику функции $f(x)$ в точке $x_0$ описывается уравнением:
$$y = f(x_0) + f'(x_0) \cdot (x - x_0)$$
### ,где $f(x_0)$ - значение функции в точке касания, $f'(x_0)$ - значение ее производной в этой точке.
### Аналитическое решение:
## Дана кусочная функция:
$$f(x) = 
\begin{cases} 
\cos(x) \cdot e^{-x^2}, & 0 \leq x \leq 1; \\
\ln(x+1) - \sqrt{4-x^2}, & 1 < x \leq 2.
\end{cases}$$

### Для построения касательной выберем первую функцию $f(x) = \cos(x) \cdot e^{-x^2}$ на отрезке $[0,1]$. Возьмем точку касания $x_0$ - середину интервала: $x_0 = 0.5$.
### Вычислим значение функции в этой точке:

$$f(0.5) = \cos(0.5) \cdot e^{-(0.5)^2} = \cos(0.5) \cdot e^{-0.25}$$

### Так как $\cos(0.5) \approx 0.8776$, а $e^{-0.25} \approx 0.7788$, то

$$f(0.5) \approx 0.8776 \cdot 0.7788 = 0.683$$

### Таким образом, точка касания имеет координаты $(0.5; 0.683)$.
### Далее, найдем производную функции $f(x) = \cos(x) \cdot e^{-x^2}$:

$$f'(x) = -\sin(x) \cdot e^{-x^2} + \cos(x) \cdot (-2x e^{-x^2}) = -e^{-x^2}(\sin(x) + 2x \cos(x))$$

### Подставим $x_0 = 0.5$:

$$f'(0.5) = -e^{-0.25}(\sin(0.5) + 2 \cdot 0.5 \cdot \cos(0.5))$$

### Так как $\sin(0.5) \approx 0.4794$, $\cos(0.5) \approx 0.8776$, то

$$\sin(0.5) + \cos(0.5) \approx 0.4794 + 0.8776 = 1.357$$

$$f'(0.5) \approx -0.7788 \cdot 1.357 = -1.057$$

#### Подставляем значения в уравнение касательной:

$$y = 0.683 + (-1.057)(x - 0.5) = 0.683 - 1.057x + 0.5285 = -1.057x + 1.2115$$

### Итак, уравнение касательной к графику функции $f(x) = \cos(x) \cdot e^{-x^2}$ в точке $x_0 = 0.5$ есть

$$\boxed{y = -1.057x + 1.2115}$$

### Это прямая линия, которая касается графика в точке $(0.5; 0.683)$.

## Программа

```python
import numpy as np
import matplotlib.pyplot as plt

# Первая ветка функции
x1 = np.linspace(0, 1, 200)
y1 = np.cos(x1) * np.exp(-x1**2)

# Вторая ветка функции
x2 = np.linspace(1.01, 2, 200)
y2 = np.log(x2 + 1) - np.sqrt(4 - x2**2)

# Точка касания
x0 = 0.5
y0 = np.cos(x0) * np.exp(-x0**2)
k = -np.exp(-x0**2) * (np.sin(x0) + 2 * x0 * np.cos(x0))

# Касательная
x_kas = np.linspace(0.2, 1.2, 100)
y_kas = y0 + k * (x_kas - x0)

# Построение
plt.figure(figsize=(10, 6))
plt.plot(x1, y1, 'g-', linewidth=2, label='Первая ветка: cos(x)·e^(-x²)')
plt.plot(x2, y2, 'b-', linewidth=2, label='Вторая ветка: ln(x+1) - √(4-x²)')
plt.plot(x_kas, y_kas, '--', color='purple', linewidth=2, label='Касательная в x₀=0.5')
plt.scatter(x0, y0, color='red', s=80, label='Точка касания')

plt.title('График функции и касательная')
plt.xlabel('x')
plt.ylabel('y')
plt.grid(True)
plt.legend()
plt.xlim(0, 2)
plt.ylim(-1.5, 1.5)
plt.show()

print(f'Уравнение касательной: y = {k:.3f}x + {y0 - k*x0:.3f}')
```
